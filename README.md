## Project Description

The **AI-Powered Agile User Story Classification and Priority Prediction** system is designed to assist Agile development teams in automatically analyzing and prioritizing user stories. User stories are provided as textual inputs, and Natural Language Processing (NLP) techniques are used to extract meaningful information from them.

The system classifies user stories into relevant categories and predicts their priority based on the content and characteristics of the story. By automating these activities, the proposed system can reduce manual effort, improve consistency in backlog management, and help Agile teams focus on high-priority requirements.

---

## Objectives

* Automatically classify Agile user stories into relevant categories.
* Predict the priority of user stories using machine learning.
* Apply NLP techniques to process textual user stories.
* Reduce manual effort in backlog management.
* Improve consistency in user story prioritization.
* Provide an easy-to-use interface for entering and analyzing user stories.
* Display classification and priority prediction results clearly.

## Setup and Execution Instructions

### 1. Clone the Repository

```bash
git clone <repository-url>
```

### 2. Navigate to the Project Directory

```bash
cd AI-Powered-Agile-User-Story-Classification-and-Priority-Prediction
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

**Linux/macOS:**

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Streamlit Application

```bash
streamlit run src/app.py
```

### 7. Open the Application

After running the command, Streamlit will provide a local URL, typically:

```text
http://localhost:8501
```

Open the URL in a web browser to use the application.
